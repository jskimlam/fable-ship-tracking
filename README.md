# 페이블 쉽트래킹 (FABLE SHIP TRACKING)

석유화학 원료·제품 탱커선을 **갱신 버튼을 눌렀을 때만, API 없이 직접 조회**해서 보여 주는 안드로이드 앱입니다.
피클마린트래킹(`pickle-marine-tracking`)의 후속으로 새로 작성했습니다.

## 설치

1. 폰에서 [최신 릴리스](https://github.com/jskimlam/fable-ship-tracking/releases/latest)를 열고 `fable-ship-tracking.apk` 를 받습니다.
2. "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다. 새 버전은 기존 설치본 위에 덮어 설치됩니다.

`main` 에 커밋이 올라갈 때마다 GitHub Actions 가 테스트 후 APK 를 빌드해 릴리스에 올립니다.

## 직접 조회 방식

| 순서 | 소스 | 읽는 값 | 상태 |
|---|---|---|---|
| ① | Wingo Marine 공개 선박 페이지 (주 소스, 로그인 불필요) | 정밀 좌표, 24시간 항적, 속력·침로·선수방향, 목적지, 수신 시각, 제원 | 2026-11-11 실제 화면으로 검증 |
| ② | VesselFinder 선박 상세 | 직전 항만·출항 시각, AIS 입력 ETA, 제원 보충 | 2026-11-11 실제 화면으로 검증 |
| ③ | 여수항도선사회 도선예보 | 도선사 승선 예정 시각, 출발지·선석, 대리점 | 2026-11-11 실제 화면으로 검증 |
| ④ | 사용자 지정 소스 | 좌표·속력·침로 (범용 규칙) | 추가 교차 확인용 |

선명·번호 검색도 Wingo 공개 검색을 직접 조회한다. Wingo 로그인은 필수가 아니며, 앱 안 브라우저에서 로그인해 두면 위성 조회 같은 계정 기능을 같은 세션으로 쓸 수 있다.

- 앱이 숨은 웹뷰로 해당 페이지를 실제로 열고, 화면에 보이는 글자를 읽어 해석합니다. API 키·유료 전환 대상 API 를 쓰지 않습니다.
- 통신은 갱신·찾기를 눌렀을 때만 일어납니다. 상시 수신·백그라운드 통신은 없습니다.
- 로그인이 필요한 소스는 설정의 "열기·로그인"에서 사용자가 직접 로그인합니다. 앱은 비밀번호를 읽거나 저장하지 않습니다.

### 알아 둘 한계

- 정밀 위치와 24시간 항적은 Wingo 에서 읽습니다. VesselFinder 무료 화면의 좌표는 1도 단위라 "개략 위치"로만 표시하고 항적에 넣지 않습니다.
- Wingo 연안 수신도 외해(동중국해 한가운데 등)에서는 몇 시간씩 끊길 수 있습니다. 그동안은 추측항법(추정) 표시로 메워집니다.
- 사이트 화면 구성이 바뀌면 `js/parsers.js` 의 해당 소스 규칙을 고쳐야 합니다.
- 사이트가 보안 확인(사람 확인)을 띄우면 앱이 우회하지 않습니다. "원문 열기"에서 직접 통과한 뒤 다시 갱신합니다.
- 각 사이트의 이용약관은 사용자가 확인해야 합니다. 조회는 사람이 버튼을 누를 때 한 척씩 차례로만 합니다.
- 항로는 표시·ETA 추정용 개략선입니다. 항해 계획이 아닙니다.

## 화면에서 실측과 추정을 구분하는 법

| 표시 | 뜻 |
|---|---|
| 청록 선박·실선, `실측` 꼬리표 | 소스에서 읽었거나 직접 입력한 위치 |
| 호박색 선박·점선, `추정` 꼬리표 | 마지막 실측 이후 같은 속력으로 항로를 따라갔다고 계산한 위치(추측항법) |
| 보라색 넓은 원 | 1도 단위 개략 위치 |
| `미확인` | 값이 없음. 임의의 좌표·ETA 를 만들지 않습니다 |

대표 ETA 는 도선예보 → 계산 ETA → AIS 입력 ETA 순으로 고릅니다.

## 폴더 구성

```
android/                     안드로이드 프로젝트 (외부 라이브러리 의존성 없음)
  app/src/main/java/…/MainActivity.java     앱 화면 + 직접 조회 엔진(숨은 웹뷰)
  app/src/main/java/…/BrowserActivity.java  앱 안 브라우저(로그인·원문 보기)
  app/src/main/assets/www/                  화면 전체 (HTML/CSS/JS)
    js/parsers.js    소스별 읽기 규칙        js/engine.js   갱신 순서·항차 계산
    js/route.js      육지 회피 항로          js/brief.js    대화형 브리핑
    js/mapview.js    지도·애니메이션         js/ui.js       화면 조립
    js/data/         항만 DB, 육지 마스크, 해상 그래프, 예시 응답
tests/core.test.cjs          회귀 테스트 (node --test tests/core.test.cjs)
tools/build-geo.cjs          육지 마스크·해상 그래프 생성 도구
```

PC 브라우저에서 `android/app/src/main/assets/www/index.html?demo=1` 을 열면 2026-11-11 에 받아 둔 예시 응답으로 화면을 미리 볼 수 있습니다.

## 서명 키

`android/keystore/fable-sideload.jks` 는 개인 설치용으로 저장소에 공개해 둔 키입니다(비밀번호도 `build.gradle` 에 있음).
업데이트 APK 가 기존 설치본을 덮어쓸 수 있게 하려는 용도이며, 스토어 배포에는 쓰지 마세요.
